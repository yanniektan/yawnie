# Cta parents

## Steps

1. Read the day's other blocks from the runner.
2. Write one or two first-person sentences from those facts, such as 'I went for a long run'.

## Returns

a message block with the draft.

## Guardrails

- Never see or describe the photo.
- The user presses Send in Messages. This skill cannot send.

Call only the tools listed in tools.json.
